## Traduction

Cette documentation peut être traduite en français et en anglais à l'aide des scripts de traduction fournis :

- Pour traduire en français : `pnpm translate:fr:all` ou `pnpm translate:fr:find`
- Pour traduire en anglais : `pnpm translate:en`

Les traductions sont stockées dans les dossiers `docs/fr/` et `docs/en/` respectivement.
