Développez TypeScript, Node.js et Next.js Applications suivant les conventions et les directives.

** style de code et structure **

- Écrivez le code concis et type technique à l'aide de modèles de programmation fonctionnels et déclaratifs.
- Évitez les cours; Préférez l'itération et la modularisation à la duplication de code.
- Utilisez des noms de variables descriptifs avec des verbes auxiliaires (par exemple, `Isloading`,« Haserror »).
- Structure des fichiers dans: composant exporté, sous-composants, assistants, contenu statique et types.

** Conventions de nommage **

- Utilisez des minuscules avec des tirets pour les répertoires (par exemple, `Composants / Auth-Wizard`).
- Faveur nommée exportations pour les composants.

** Utilisation dactylographiée **

- Utilisez TypeScript pour tout le code; préfèrent les types aux interfaces.
- Évitez les énumérations; Utilisez des cartes à la place.
- Utilisez des composants fonctionnels avec des types de typeScript.

** Syntaxe et formatage **

- Évitez les accolades bouclées inutiles dans les conditions; Utilisez la syntaxe concise pour des instructions simples.
- Écrivez JSX déclaratif.

** UI et style **

- Utilisez Ui Shadcn, Radix et Tailwind pour les composants et le style.
- Implémentez la conception réactive avec Tailwind CSS à l'aide d'une approche mobile axée sur le mobile.

** Optimisation des performances **

- Minimiser `Utilisez le client ',` useEffecct` et «SetState»; favoriser les composants React Server (RSC).
- Enveloppez les composants du client dans le «suspense» avec le secours.
- Utilisez un chargement dynamique pour les composants non critiques.
- Optimiser les images: utilisez le format WebP, incluez des données de taille et implémentez le chargement paresseux.

** Création du modèle de requête de la base de données et du modèle de données **

- Utilisez Prisma SDK pour interroger la base de données.
- Pour les modèles de données, lisez les fichiers «.prima».

** Conventions clés **

- Utilisez des «nuqs» pour la gestion des paramètres de recherche d'URL.
- Optimiser les vitaux Web (LCP, CLS, FID).
- Limit 'Utiliser le client': Faver les composants du serveur et Next.js SSR pour la récupération des données ou la gestion de l'état.
- Utiliser «Utiliser le client» uniquement pour l'accès à l'API Web dans les petits composants.

** PostgreSQL **

- Utilisez une syntaxe postgresql valide avec des guillemets pour les noms de table et de colonne.
